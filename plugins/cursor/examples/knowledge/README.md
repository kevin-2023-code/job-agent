# knowledge/

Drop anything here that should inform your search. The agent searches this folder before it answers a question about a company, an interview or your own history. Nothing in it is committed.

Good things to put here:

- **Interview notes**: what you were asked, by whom, how it went. One file per loop, e.g. `interviews/2026-11-stripe-onsite.md`.
- **Company research**: team pages, engineering blog posts, news you saved, notes from people who work there.
- **Recruiter threads**: paste the emails (they often state level, range and timeline).
- **Past offers and comp data**: helps the agent judge whether a range is good for you.
- **Prep material**: your own notes on system design, the problem patterns you get wrong, mock feedback.
- **Performance reviews and brag docs**: the best raw material for CV bullets and stories.

Markdown and plain text work best. Run `job-agent kb index` after adding files, so the agent gets a table of contents in `knowledge/INDEX.md`.
