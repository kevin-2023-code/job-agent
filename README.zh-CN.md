# job-agent

把你已经在用的 AI 编程助手（Claude Code、Codex、Cursor、Copilot、Gemini CLI）变成一个求职助手，在你本机的一个文件夹里运行。

它会按你真正想要的东西给岗位打分；扫描目标公司的招聘页，找出新岗位；针对每个岗位改简历，但不编造任何内容；把每份申请表的答案准备好，由你自己提交；维护投递记录；再帮你准备接下来的面试。简历、笔记、投递记录都是这个文件夹里的普通文件。除非你自己接入了别的服务，否则什么都不会上传。

## 能做什么

| 你说 | 技能 | 会发生什么 |
| --- | --- | --- |
| "帮我初始化" + 简历 | `job-setup` | 生成 `profile/cv.md`、求职目标、硬性排除条件、STAR 故事草稿和要关注的公司列表 |
| "这个岗位值得投吗？" + 链接 | `job-evaluate` | 按六个加权维度给出 A–F 评级；每条硬性要求对应到你简历里的哪一行；列出差距和风险；在 `reports/` 写一份两分钟能读完的报告 |
| "有新岗位吗？" | `job-scan` | 读取目标公司在 Greenhouse、Lever、Ashby、SmartRecruiters 上的公开招聘页，按职位名、地点、发布时间筛选，去掉看过的，剩下的做初筛 |
| "针对这个岗位改简历" | `job-tailor` | 生成一份定制简历，每处改动都给你确认，导出 PDF；需要时再写求职信 |
| "帮我投这个" | `job-apply` | 读申请表，用你的资料逐项填答案，起草开放题，交给你一份可以直接复制的答案单。提交由你自己点 |
| "Stripe 下周约了电话面" | `job-track` | 更新投递记录，设好跟进时间，用真实数据告诉你哪些做法有效 |
| "帮我准备 onsite" | `job-prep` | 按轮次拆解流程，列出可能的题型，排每日计划，把故事对应到行为题，再做模拟面试并给出直接的反馈 |

## 不会做什么

- 不编造你的任何经历。它写下的每一行都能追溯到你的文件或你说过的话。
- 不替你提交申请，不发邮件，不联系任何人。它只起草，发送由你来。
- 不登录、不注册账号、不碰密码、不做验证码。
- 不替你回答自愿披露的身份类问题（性别、种族、残障、退伍等）。

这些规则写在 [`AGENTS.md`](AGENTS.md)，所有支持的 agent 都会读。

## 快速开始

需要 Node 18+，以及一个能读文件、能执行命令的 agent。

```bash
git clone https://github.com/kevin-2023-code/job-agent.git
cd job-agent
npm install
npm run setup
```

然后用你的 agent 打开这个文件夹，附上或粘贴简历，说 **"帮我初始化"**。之后贴岗位链接就行。

## 你的数据

`profile/`、`knowledge/`、`data/`、`reports/`、`output/` 和 `portals.yml` 都在 `.gitignore` 里。投递记录是 TSV，任何表格软件都能打开。

agent 知道多少，取决于你给了它多少。**`knowledge/` 是越用越值钱的地方**：以前的面试笔记、工作成果记录、绩效评价、朋友讲的团队情况，都可以放进去。回答任何关于公司或你自己经历的问题前，agent 会先搜这里。

## 更多数据（可选）

只靠本地，agent 知道的是你的文件、岗位描述和网上能搜到的内容。它不知道的是其他候选人遇到了什么：这家公司今年的面试流程、具体问了什么。这部分可以自己在 `knowledge/` 里慢慢积累，也可以通过 MCP 接一个数据源。[`docs/data-sources.md`](docs/data-sources.md) 两种方式都有说明，其中包括 [TrueInterview](https://trueinterview.io)（按公司整理的面经、题库、实时岗位和匹配度评分，需要账号）。这个仓库的任何功能都不依赖它。
